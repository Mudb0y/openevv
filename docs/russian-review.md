# Чеклист русской ветки

Проверка выполнена 18 ноября 2026 года на Windows x64. Сборки содержат все 13 языков. Побайтовое сравнение использует прежнюю русскую DLL из `D:/evvdroid/native/openevv/build/eci.dll` и её `rulex.dat`. Эталон используется для проверки.

## Модуль и звучание

- [x] Русский модуль хранится в `lang/ruru` и подключается через `LANGS`.
- [x] Русские буквенные правила, числа, ударение, редукция и слогоделение работают в правилах модуля. Прежний текстовый C-препроцессор удалён.
- [x] Акустическая основа US English сохранена по выбору пользователя.
- [x] Согласование тысяч, группы цифр, проценты, порядковые числительные, даты, десятичные дроби, сокращения и символы проверены на примерах.
- [x] Положение принудительной паузы вычисляется по длине фонетической записи. Проверены последовательные окна длинной реплики.
- [x] Число слогов при чтении наперёд считается по русским гласным.
- [x] 78 из 78 сравнений фонем, слоговых меток и PCM совпали при 11 025 Гц в сборках C и bytecode. Проверки охватывают обычный текст, UTF-8, аннотации ECI, SSML и целевые примеры.
- [x] Четыре дополнительные длинные реплики из `test/cases/long-ruru.txt` совпали в обеих сборках.
- [x] Расширенная проверка 60 длинных реплик прошла в bytecode. Четыре последовательные реплики на одном экземпляре также совпали побайтно.

Для повторения сравнений нужен путь к эталонной DLL и переменная `EVV_RULEX`, указывающая на её словарь.

```powershell
python test/ruru-parity.py --dll --phones <reference-dll> build/eci.dll --cases test/cases/plain-ruru.txt
python test/ruru-parity.py --dll --phones <reference-dll> build/eci.dll --cases test/cases/utf8-ruru.txt
python test/ruru-parity.py --dll --phones --annotations <reference-dll> build/eci.dll --cases test/cases/anno-ruru.txt
python test/ruru-parity.py --dll --phones --ssml <reference-dll> build/eci.dll --cases test/cases/ssml-ruru.txt
python test/ruru-parity.py --dll --phones <reference-dll> build/eci.dll
python test/ruru-parity.py --dll --phones <reference-dll> build/eci.dll --cases test/cases/long-ruru.txt
```

- [x] Исправлены чтение UTF-8 на границе буфера и освобождение временных буферов при ошибке японского романизатора.

- [x] Проверены русские таблицы и генераторы. 921 отобранное слово и 286 745 форм OpenRussian воспроизводят оба файла словаря побайтно.

- [x] Окно Windows читает Unicode и выбирает кодовую страницу выбранного языка.
- [x] Библиотечные проверки переключения и одновременной работы языков, словарей, пауз, скобок и восстановления после отказа проходят.
- [x] Заключительная матрица всех языков прошла по 1 485 из 1 485 проверок в каждой из четырёх сборок Windows x64 и x86, для C и bytecode.
